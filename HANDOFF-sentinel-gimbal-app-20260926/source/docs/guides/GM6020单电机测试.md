# GM6020 单电机测试

本入口只用于独立台架的一颗 CAN1 / GM6020, 不是整车控制程序. 电机须已启用支持电流环的固件及内置电流环; 不自动回退电压模式. 测试安全依托现有物理电源硬切, 不增加整车联锁、确认向导或恢复状态机.

**当前交付的是可采波形的软件, 不是已经调稳的控制器.** 速度发散、位置抖动的实测状态与离线证据只维护在 [实施与验收 S5](../robots/sentinel/实施与验收.md#s5-单电机与单机构).

## 1. 固件与映射

按 [板级生成与构建](../boards/sentinel_f407/生成与构建.md#11-s5-gm6020-单电机镜像) 构建独立 S5 目录. `EC_S5_GM6020_BENCH` 默认关闭. S5 镜像仍名为 `sentinel_s1.elf`, 必须按构建目录与审计角色区分, 不能按文件名认定为非运动镜像.

- `EC_S5_GM6020_ID=1..7` 同时决定设备、接收 ID、命令组和槽位; 不修改电机保存 ID. 当前默认 **4**; 现场 ID 的确认与实测状态见上述验收入口. 更换台架时先被动核对, 不继承旧台架的 ID 假设.
- ID1–4: 命令 `0x1FE`, slot=ID−1; ID5–7: 命令 `0x2FE`, slot=ID−5. 反馈为 `0x204+ID`. 固件读回映射不等于已收到真实反馈.
- S5 独占 CAN1 TX, 同组其余槽发零; 仅用于已隔离的单电机台架, 不与其他发送者共用.
- 协议 **S5/v6**, 标记 `0x53354236`. 状态126 B、参数42 B, 必须同时更新固件和面板; 不混用旧版(包括v4/v5). 已保存的v4原始波形仍可离线读取.
- 控制仍复用正式 `DjiAxis` / `PositionLoop` / `VelocityLoop` / `Pid` / `DjiDevice` / `DjiTxGroup`. 控制 dt 改为 TIM5 实际微秒差, 不是名义 1 ms 或毫秒取整; 没有另造台架 PID.

## 2. 操作入口

### 2.1 Dear PyGui 调试控制台 (推荐)

范围仅为当前独立GM6020台架, 复用S5/v6协议与原串口拥有者; 不连接正式APP或DM, 无需为此更换固件. 项目 `.venv` 安装 `requirements-dev.txt` (含 Dear PyGui 2.3.1). 在仓库根目录运行:

```powershell
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench_console.py --port COM3
# 只看已有波形, 不连接串口、不产生运动
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench_console.py --trace build/motor-bench-logs/<run>.btrace
```

- 启动不自动连接, 连接只查询. 首次使用点“用MCU回读值填入草稿”, 或打开保存的候选; 不自动预填一组声称已调稳的PID. 当前MCU配置也不代表稳定参数.
- 顶部突出MCU目标、实际运动、误差与命令电流; 输出禁用与机械静止是不同状态. 速度卡显示原生RPM, 控制反馈源另行标明; 编码器估计为滤前量, 真正参与控制的内环值需看完整波形. 电流模式没有可靠的实测A反馈, 不伪造跟踪误差.
- 左侧只编辑草稿, 读回值在“MCU回读/诊断”页. 参数按次锁定, 运行中“更新当前模式目标”不采用草稿PID/反馈源. 改模式也只是草稿, 不自动启停; 跨模式目标更新不可用.
- 速度模式增加 `−2 / −0.5 / +0.5 / +2 / 反转` 快捷按钮, 以目标输入框为基值, 点击立即发送阶跃目标 (不使用斜坡输入值), 不改变PID或原运行截止时间. 仅在已运行的速度模式可用; 超过MCU当前速度目标上限则不发送、不暗中裁剪.
- 位置模式增加 `−0.1 / −0.01 / +0.01 / +0.1 rad` 快捷按钮, 以目标输入框为基值立即阶跃更新, 不使用斜坡输入值. 仅运行中的位置模式且参考有效时可用, 不重新启停/建立参考、不清PID历史、不改变运行截止时间. 目标是相对累计角, 不按单圈裁剪或编码器计数取整.
- 1s平均速度使用最近完整1秒原生RPM状态, 按主机接收时间作梯形积分/时间加权, 不是1kHz全量统计. 不足1秒、断样或反馈失效时显示 `—`, 连续有效窗口恢复后重新显示; 不参与控制.
- 操作面板中的停止按钮和 **F8** 请求停止输出; 不使用空格全局快捷键, 避免输入备注时误触. 仍不是物理急停. 关闭窗口/断开沿用原来的停止请求, 不将串口写成功宣称为机械停止.
- “实时观测”是约10 Hz状态快照、主机接收时间轴, 最多保留600点. 过期隐藏实时数值, 曲线保留的是历史; 断样断线不插值. 不是实时1 kHz性能记录.
- “高频记录/回放”支持完整1024周期与精简2730周期, 可立即采集或等待下一次启动/目标更新触发. 采集/下载不改变运动目标, 串口线程继续心跳. 下载后自动打开 `.btrace`, CSV/PNG通过“导出A”按需生成, 不在串口线程绘图.
- A/B对照均从各自窗口起点对齐, 不假定它们处于同一实验阶段. 图例可切换曲线, 鼠标滚轮缩放/拖动平移; 速度图的绿色/黄色线或选区输入框计算区间RMS、峰峰值及缺口. 位置有效时提供位置误差统计. 精简记录缺少的PID和相对位置不补零; 窗口统计不自动判定调稳.
- 候选文件保存当前草稿及备注, 默认 `build/motor-bench-logs/candidate.json`; 同名不覆盖, 可自行改名管理候选. 打开只填草稿, 不下发、不使能、不写MCU Flash/电调. 候选文件与 `.btrace` 工况元数据不是同一种文件.
- 默认加载Windows微软雅黑; 可用 `--font <TTF或TTC路径> --font-size 20` 调整字体. 图表高度随窗口可用高度分配, 图例放在绘图区内; 小窗口保留最低图高并左右各自滚动, 建议1240×880或更大. 不自动改变系统DPI配置.

### 2.2 原 Tkinter 面板 (保留)

Python 需包含 Tcl/Tk (当前控制台复用原模块也会导入它). 在仓库根目录运行:

```powershell
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench.py --port COM3
```

可用 `--firmware build/bench-b0-arm-Release/boards/sentinel_f407/sentinel_s1.elf` 把本地工件路径与 SHA256 写进采集元数据. **这是操作者提供的工件身份, 不是 MCU Flash 回读校验**; 实际烧录对应关系由烧录/校验日志确定.

- CH340 接外壳 UART1 / USART6, 115200 8N1, 同时只由一个程序占用. 不并接模块 VCC 到已供电板卡.
- “连接”只查询. 选模式、填参数, “开始本次测试”才请求输出. 默认运行时间 `0=持续`, 可指定至 3600 s.
- 参数按次锁定; 修改增益/限幅/滤波或切模式, 停止后再开始. “更新当前模式目标”只改目标, 保留控制器历史、参考和原运行截止时间. 斜坡 `0=阶跃`, 非零为 MCU 执行的一段线性斜坡, 不是主机定时重复启停.
- 位置模式先“建立位置参考”: 当前机械角作为累计角零点, 不写编码器零位. 参考与启停独立, 停止再开始不重置参考. 反馈超时或累计角失去唯一性后, 不自动重建参考.
- “停止输出”或空格请求零电流; 不等于刹车/断电. 既有心跳 500 ms、反馈 TTL 50 ms、控制步长上限 30 ms、CAN 发送失败撤输出和重连不恢复旧目标保持不变. 采集/绘图错误不撤销电机目标.
- “测试: 停发心跳”只用于已有时效测试, 不是正常操作必经步骤. 不再要求验收打卡或多层确认. CAN 断线/MCU 停核不能保证零帧送达, 运行中不用 SWD 停核代替波形观测.

## 3. 目标、参数和单位

以下目标预填与旧换算默认值属于原Tkinter面板; 新控制台通过读回或候选载入参数, 不自动沿用这些值.

| 模式 | 目标预填 | 实际控制链 |
|---|---|---|
| 电流 | 0.2 A | 电流目标 → 电调内置电流环 |
| 速度 | 1 rad/s | MCU 速度 PID → 电流目标 |
| 相对位置 | 0.5 rad | MCU 位置 P → 速度目标 → 速度 PID → 电流目标 |

预填不会自动执行. 速度零目标是闭环抑制转动, 位置零目标是保持参考点, 均不等于停止输出. 电流上限最多 3 A、速度目标上限最多 60 rad/s 是接口量程, 不是任何负载下的性能保证. 无新增 ±90° 目标限制、自动超速停止或自动整定策略.

旧主 yaw 有效参数换算如下, **不是稳定参数保证**:

| 参数 | 来源/默认 |
|---|---|
| 速度 Kp | `73 raw/(deg/s) × (180/π) × (3/16384)` ≈ 0.765855 A·s/rad |
| 速度 Ki / Kd | 0 / 0, 单位分别 A/rad、A·s²/rad |
| 电流输出上限 | `3000 × 3/16384` = 0.549316 A |
| 位置 Kp | 7.5 s⁻¹ |
| 位置环速度上限 | 200 deg/s = 3.490659 rad/s |
| 速度反馈 alpha | 默认 0, 即不滤波; `[0,1)` 越大越偏重历史测量, 作用于整个速度反馈 |
| 独立 D 低通 tau | 默认 0 s关闭; 正值使用实际dt的一阶后向Euler低通, 只作用于微分, 不延迟P/I |
| 编码器测速 | 默认关闭使用原生RPM; 勾选后速度/位置内环使用最近5个已到达编码器样本的线性拟合, 不外推、不改变机械参考 |

旧实现有系数 0.9 的速度滤波及位置 D=0.005; 当前不自动照搬. v6 提供显式速度 Kd/整条反馈滤波及独立D低通配置, 三者默认仍为零. D低通状态随PID重置而清除, 更改目标不产生微分冲击; D诊断记录过滤后的实际输出. 固件在构造轴时把 A 域增益一次性换到“所设电流上限的分数”域; 不重复换算, 不因采集功能暗改默认增益. 空载与实车惯量、线缆扭矩不同, 应分别整定两根 yaw.

编码器是单圈绝对编码器, 不能恢复掉电期间累计圈数. 电流反馈只标为厂商 `effort_raw`, 不按命令比例擅自换算 A. CAN 接收时刻不是电调内部采样时刻; `accepted` 仅表示本地发送接口接受请求, 不证明已上总线或电流已跟踪.

S5提供编码器测速的显式选择; 当前单GM/四电机APP台架另在固件中固定启用GM6020五点测速, 正式维护台尚无切换项, 整车默认反馈源未改. 算法及推广边界见[DJI轴门面](../modules/motion/DJI轴门面.md) §4.1. 使用真实CAN接收微秒间隔, 1kHz下窗口中心约滞后2ms; 状态报告估计值、中心年龄(毫秒向上取整)及有效位. 样本重复不重复求导, 达既有50ms反馈期限的断样后重建窗口, 不偷换回原生RPM. 完整快窗的 `velocity_used` 为实际内环测量, 原生RPM仍独立保留. CLI通过 `--encoder-velocity` 开启; 采样/编码器量化误差、实际时延与性能必须实测, 不把因果回放或旧RPM等效模型视作新反馈源的物理验收.

## 4. 采样、保存与波形

1. 填可选工况备注 (供电、安装轴向/固定方式、负载等). 没填就留空, 不自动假定是竖直轴或已标定.
2. 选 `1..1024` 条, 点击“采集波形”. 不勾触发时立即录下一周期, 可采零输出基线. 勾触发时先在 MCU 预置, 再用“开始”或“更新目标”触发; 以 MCU 事件位对齐, 不用 PC 发包时间猜测.
3. 每个真实控制周期保存 64 B, **不抽点**, 1 kHz 名义上约覆盖 1.024 s. 满窗冻结, 不覆盖. “结束采样/导出”只结束日志, 不停止电机. 新一次启动导致参数代次改变时结束旧窗口, 不混用两套参数.
4. 冻结后才读取数据, 每响应最多 3 条. 现有串口导出耗时数秒以上, **不是实时 1 kHz 全量串流**. 串口线程仍调度心跳与停止; PNG 绘制在独立线程, 不阻塞串口线程.
5. 原始 `.btrace` 与会话 JSONL 保存在 `build/motor-bench-logs/`. 原Tkinter面板自动生成同名追加 `.csv`、`.summary.json`、`.png`; 新控制台下载后打开交互波形, 通过“导出A”按需生成上述文件. 图/统计仅帮助判断, 没有自动“调稳/通过”结论. 本轮只实现完整周期快窗; 未做可选块统计慢窗, 约10 Hz状态快照不能证明没有高频振荡.

离线重新导出 (不打开串口):

```powershell
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench_trace.py build/motor-bench-logs/<run>.btrace
# 只导出 CSV 与窗口统计
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench_trace.py build/motor-bench-logs/<run>.btrace --no-plot
```

同一周期记录:

- TIM5 计算开始、CAN 接收与实际 `CanTx::try_send` 调用时刻、实际 dt; 反馈/周期序号低16位用于短窗判缺口.
- 原始编码器、原生 RPM、厂商电流反馈 raw、关节角、真正参与内环的反馈及速度目标.
- 实际 PID 的 P/I/D、限幅前值、内/外环饱和、实际传给 CAN 接口的电流字; 不是在 Python 重算积分/微分或再次编码来代替实发证据.
- 模式、执行/反馈/参考有效位、目标/参考事件、斜坡状态、停止原因、轴与组发送结果.

PID 分项按其真实归一化单位保存, Python 使用**同窗起始参数**换算 A. 未计算的 PID、失效位置、未接受的发送不画成有效零值. CSV 同时保留原始字段与有效位, 使用时须一起判断. 接受的电流字可换算命令 A, 但不是实测电流. 反馈序号是 MCU 接受的帧计数, 不能证明电调未丢帧; 板级队列/错误计数、调度/栈峰值仍在 B1 同时观测.

元数据含 run、起止 MCU 状态/时刻、完整参数、配置/参考代次、设备映射、固件 build ID、可选本地工件 SHA256、工况备注及原始记录摘要. 文件为 `BTR1` + little-endian u32 JSON长度 + UTF-8 JSON + 原始定长记录. 图以 MCU 时间轴展开微秒回绕, 不跨无法确定的时间缺口拼曲线.

## 5. 辨识工具 (B2)

完整快窗继续为1024×64 B. 新增辨识长窗 `BID1` 在同一64 KiB缓存保存2730×24 B, 名义覆盖2.73 s, **每个控制周期均记录, 不抽样**. 保留计算/反馈接收时刻、实际目标、编码器/RPM、实际命令字、周期序号与有效/饱和/停止/提交状态; 不保存PID分项、参考位置、精确提交时刻. 导出缺失项为空, 不伪造零值. 长窗dt从相邻计算时刻得到, 首条未知; 全部PID诊断仍用完整快窗.

`motor_bench_experiment.py` 只用于已确认的单GM6020台架: 明确端口、固件工件、输出新目录和参数. 支持有限阶跃/斜坡、MCU定时正弦/方波, 结束请求零输出并确认响应. 激励只更新现有模式目标、不重置积分; 激励段结束保持bias, 原运行截止和心跳仍有效. 同模式目标更新/停止/重新启动清掉旧激励. 方波仅适用当前允许的自由旋转台架, 不直接用于实车限位机构. 没有隐式自动扫描、硬件试参或电调持久写入.

```powershell
# 有运动: 仅在明确授权的ID4台架执行; 数值为示例实验, 不是调稳参数.
./.venv/Scripts/python.exe boards/sentinel_f407/tools/motor_bench_experiment.py `
  --port COM3 --id 4 --firmware build/bench-b2e-arm-Release/boards/sentinel_f407/sentinel_s1.elf `
  --output build/gm-ident/example --mode current --target 0.08 --seconds 2 --kp 0 --derivative-tau 0 --compact
```

离线分析入口:
- `motor_bench_identify.py --train <记录...> --validate <独立记录...> --output <新JSON>`: 按实际已提交电流命令, 拟合等效增益/阻尼/库仑项/总延迟; 使用已停止后启动的记录, 窗口前命令按零处理. 参数不是独立物理Kt/J, 不是实测电流. 留出失败即保留模型失配, 不用训练拟合率替代验证.
- `motor_bench_tune.py --model <JSON> --native <ec_gm6020_ident_sim.exe> --output <新JSON>`: 在主机原生 `Gm6020Bench/DjiAxis/Pid/DjiTxGroup` 与命令字链上筛选PI候选. 模型未通过选用条件不生成参数. ±20%模型增益仅为敏感性场景, 不是统计置信区间. 所有输出 `deployment_ready=false`, 不自动发给电机.
- 仿真对象当前只支持等效一阶机械动态、库仑摩擦和延迟. 无法解释起动/齿槽/电调动态时必须补实测或模型, 不能用此模型宣称真实稳定. 不替换既有APP功能SIL夹具.

## 6. 协议和实现入口

线封装仍为 `UartFrameDecoder` 的版本/长度/序号/CRC, 单客户端串行请求:

| 请求 | 载荷 | 响应 |
|---|---|---|
| `0x20` 查询 / `0x23` 停止 / `0x24` 建立参考 | 空 | `0xA0`, 126 B S5/v6 状态 |
| `0x21` 本次启动 | `<B10fB>`: 模式、目标、时长、电流上限、速度上限、速度Kp/Ki、位置Kp、速度Kd、alpha、D低通tau(s)、编码器测速(0/1) | 同上, 请求序号成为本次 token |
| `0x22` 心跳 | u16 token | 同上, 不重新使能 |
