云台独立机械调试 HANDOFF

本包只驱动main yaw、fire yaw、pitch. 先完成机械位置闭环, 不需要先做惯性稳向, 不控制底盘/摩擦轮/拨弹. 不自动回零、扫参数或探测硬限位.

1. 已确定的配置

机构接线/ID保留的0位本版坐标
main yaw / GM6020CAN1 ID4, 反馈0x208编码器1027, 主平台对齐车头原生编码增大为正, 标记为0
fire yaw / GM6020CAN1 ID6, 反馈0x20A编码器2017, fire对齐主平台原生编码增大为正, 标记为0
pitch / J4310 MITCAN1控制1, Master反馈0p16=34282, 枪口近水平原生角减旧标记偏置; 保留原生方向

• 三个标记来自09252124, 没有用CAD姿态或开机位置替代. 目标0表示回到标记, 不表示原地保持.

• 两yaw上电从单圈编码恢复相对标记最近的一圈角度, 随后连续跟踪. main可跨圈; 掉电或长时失去反馈不保留累计圈数, 不声称恢复过去转了几圈.

• fire/pitch实际机械端点待人工实测, 本版不填写猜测限位. 尚无软件机械行程保护, 不能用“未拒绝目标”判断机械可达.

• pitch保留已读取的MIT映射范围PMAX=12.5rad/VMAX=30rad/s/TMAX=10N·m, 它们不是机械行程. 不把Gr=10再除一次.

• 底盘与发射机构仍占其已知地址但只撤输出; 不用本镜像调其它机构.

2. 准备与刷写

1. 固定车体, 清空弹丸并隔离发射风险; 云台周围和线束留出活动空间. pitch上电及撤目标时会失能, 先用可靠支撑防止机构下落, 不靠手夹在机构内承重.

2. 遥控右拨杆下位, 动力断开后通过SWD烧录. 本包固件前缀app-gimbal-, 不是单GM/四电机台架固件.

3. PC接C板丝印UART2 / USART1 / 921600, TX/RX交叉、共地、不接VCC, 不与Jetson发送端并联. DT7接DBUS.

4. 解压到短路径, 例如E:/gimbal. 在包根目录执行:

`powershell

python -m venv .venv

.venv/Scripts/python.exe -m pip install -r requirements.txt

.venv/Scripts/python.exe source/boards/sentinel_f407/tools/firmware_tool.py

`

选择 APP / 实车云台机械调试, “烧录已有固件”. 默认ELF为source/build/app-gimbal-arm-Release/boards/sentinel_f407/sentinel_app.elf. 填本机OpenOCD/scripts、ARM工具链、PowerShell7和本包Python路径. 仅刷已有镜像不需要CMake/SDK; 重建才需要. 只擦镜像覆盖扇区并校验, 不整片擦除、不做Flash备份、不改Option Bytes.

3. 上电后这样操作

`powershell

.venv/Scripts/python.exe source/robots/sentinel/host/sentinel_console.py --serial COM3 --mechanism gimbal --log-dir records/app

`

1. 保持右下, 供电并连接. 确认固件标识、三轴新鲜反馈及当前关节角. 连接不会自动驱动, 不需要再录一轮映射或重新标0.

2. 切到右上＋左中, 点击“申请维护”. 两版实车都保留真实遥控首启. 右下始终撤输出; 其它档位待机, 所有摇杆和拨轮均不产生动作目标.

3. 先只勾选main yaw通道, 参考选joint. 用“取当前角到目标草稿”复制当前角, 点击“下发 / 更新目标”先原地保持. 稳定后相对这个数值做小步, 例如±0.02rad, 返回原目标. 不直接填0跨越一大段角度.

4. F8撤目标, 再对fire yaw重复同样过程. 不点击“确认已知关节参考”把当前位置强行置0; 该镜像已有旧标记参考, 矛盾align会被拒绝.

5. pitch先支撑好, 只勾选pitch, 同样复制当前关节角并提交保持. 确认MIT执行和承重后再小步调整. 失能会失去主动承重; 撤目标、换机构或断电前先恢复物理支撑.

6. 三轴分别稳定后, 可勾选多个通道并分别填当前角, 同时保持/调整. 每次提交是完整目标包, 未勾选通道会撤销原目标, 不是自动沿用上次保持.

7. 抖动或方向异常时F8/右下, 必要时物理断动力. 记录当前参数、软件角度及实际运动方向, 不用负PID改方向.

GUI参数输入是草稿, 要单项“应用”并核对MCU读回. F8撤本会话目标但保留会话, 目标0则仍为位置闭环. 本版不开local_inertial/odom目标, 不做主yaw稳向或小陀螺.

4. 参数与后续端点记录

• 两GM初值来自已通过台架: 物理速度PID 0.06 / 1.0 / 0, 位置P 7.5; 电流上限2.5A、外环速度上限15rad/s. 两轴使用5点因果编码器测速. 这些仅为本调试镜像的带载待调起点, 不作为正式比赛运动上限或带载性能保证.

• pitch MIT初值Kp约4.2735、Kd=0, 沿用已通过四电机台架值. 它是电机MIT增益, 不是GM串级PID; 重力负载保持效果要现场调参, 本版没有已标定重力前馈.

• 三轴正方向暂保留原生反馈方向, 不擅自声称对应俯视逆时针或抬头. 首轮记录实际方向; 最终统一坐标变更须同时处理零位偏置, 不能只翻转目标符号.

• fire/pitch端点留到实测. 在人工确认可动范围内逐步观察, 不靠电机撞停自动找限位. 把两端的GUI关节角、物理左右/上下含义写入云台参数表.csv; 不必重做整套IMU采集.

• 旧0标记保留. 若与实物明显不符, 停止这轴并回传读数, 不直接把当前姿态清零掩盖装配差异.

• GUI热改仅RAM, 保存参数候选和日志到PC; 断电恢复编译值. 配置维护入口:source/boards/sentinel_f407/include/board_app_mechanism_config.hpp. 实测边界后统一回填、重建及验证, 当前GUI不会凭空出现未配置的min/max参数.

结束: 支撑pitch → F8/右下 → 保存候选与日志 → 释放维护、断动力. 本包完成离线验证, 不是实车动作、承重或精度验收通过. 实物方向、fire/pitch边界和带载PID由本轮人工调试完成.
