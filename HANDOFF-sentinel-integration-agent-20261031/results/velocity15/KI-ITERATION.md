# 速度环 Ki 迭代：Ki=0.35 两次均通过数值筛查

## 结论

**Ki=0.35 连续两次得到 `A_numeric`**，是各档中唯一可重复通过全部判据的设置。仍需回传评审，不自动作为正式参数。

单变量：速度 `Kp=0.4`、`Kd=0`、配套位置 `6.3/0.45/0` 全程未变，仅速度 `Ki` 变化。

## 2. 退化关系是单调的

三轮把“跟踪精度”和“停稳精度”的取舍画得很清楚：

```text
Ki 0.3   → 停稳最好(1 LSB, -0.088°) 但跟踪最差(-0.038/+0.051)
Ki 0.35  → 两者都在门限内(1 LSB, +/-0.011)
Ki 0.4   → 跟踪最好(+0.009/+0.015) 但停稳不合格(6 LSB)
```

0.35 落在可行区间内部，不是边界擦线：误差约 0.011（门限 0.025 的 45%），角跨度 1 LSB（门限 3 LSB 的 33%）。两项都有余量。

峰值需求电流同时从 0.349 A 降到 0.230 A，峰值速度从 0.362 降到 0.349 rad/s，余量也变好。

- 试验期间位置外环被绕过；位置参数虽成套写入，本轮未验证位置环行为。
