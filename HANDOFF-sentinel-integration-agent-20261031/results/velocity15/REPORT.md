## 1. 本报告采用的任务范围

依据 `HANDOFF-sentinel-velocity15-20261110.zip` 中 `Agent-15秒速度验证.md`：

- 固定临时候选：速度归一化 `0.4 / 0.4 / 0`（3 A域下电流口径 `1.2 / 1.2 / 0`），配套位置 `6.3 / 0.45 / 0`。
- 单次15秒：0 → +0.25 → 0 → -0.25 → 0 rad/s，bias=0、独立电流激励=0，中间不清积分。
- 需求电流超过0.35 A或采用速度超过0.4 rad/s，由MCU当周期撤输出并结束。
- 正常/异常结束均恢复实际旧增益并核对、撤维护权；结果非A不自动追加试验或改变退出线。
- 本次速度动作旁路位置外环，不能当作横移急停方向保持的整车验收。

之前关于“必须清零速积分”“必须提高速度才算动起来”“已经定位为机械或I项问题”的说法，不是该包要求，也没有被这轮数据唯一证明。本报告以原流程、原判据和原始记录为准。
