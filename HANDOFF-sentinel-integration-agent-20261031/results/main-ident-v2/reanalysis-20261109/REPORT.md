# V2 两轮辨识：独立重新分析

## 结论

已有数据证明：0.18 A 偏置下能够建立约 ±0.95 rad/s 的连续旋转工作点，电流激励对应可观测速度响应；记录完整。它尚未给出经过质量筛选及独立验证的对象模型或 PID 候选。

此前将质量不通过直接归因为“PID 与激励打架”“积分漂移是唯一瓶颈”，以及断言“增加周期或激励幅值没有用”，均缺少证据。此次不修改固件、控制参数或采集计划，不重新采集。

## 1. 数据与重算核验

- 数据：首轮 `run-20261109T215532` 与重采 `repeat-20261109T221358`，每轮正反两向，共四份原始 CSV、242266 个样本。
- 原始 CSV 的 SHA256 记录在 `independent-analysis.json`。
- 四份记录均 complete=true，produced=consumed=实际 CSV 样本数，dropped=0；序号连续，控制/发送/电机反馈记录低位 flags 均为 7。
- 两轮根统计均为 stream_timeouts=0。样本间隔中位值约 0.985–1.012 ms。
- 按真实 excitation_start_us、测量标志、各频点的四个测量周期独立重算；拟合常数、线性趋势、cos、sin，并按 CAN 提交时间处理电流。
- 共 20 个频响复数值与原 analysis.json 最大绝对差约 1.90e-15，重算一致。
- flags 与年龄字段只说明记录中的相应检查结果；不能替代未记录的完整平台有效性历史。

## 4. 对先前推断的纠正

### 4.1 闭环辨识不等于只测到了闭环

独立输出端电流扰动为 D，总命令为 U，速度为 Y。在线性局部、扰动与 D 不相关、未触限等假设下，闭环输出端注入仍可由 YD*/UD* 估计对象 P；不需要先关闭 PID。反馈对总电流扰动分量的抑制是正常闭环行为，不能直接称为“控制器与激励打架”。

首轮正向 0.25 Hz，各周期总电流同频幅值 U 约 0.0146–0.0526 A，变化约 3.6 倍。逐周期 Y/U 的分母变小会放大波动；其相对标准差 1.250，而同批 Y/D 相对波动约 0.397。质量问题仍存在，但 repeat 不应直接等同于物理参数同等比例变化。

### 4.2 -90 度只支持“此频带积分型趋势”

幅值大致随频率下降，相位多数接近 -90 度，与惯性主导的小信号行为相容，但并未证明全域纯积分器、低阻尼、无延迟、无摩擦或电机转子惯量很小。

若 f 用 Hz，G(s)=K/s，则 |G(j2πf)|=K/(2πf)。因此 |G|×f≈1.5 对应 K≈9.42，而不是 K=1.5。此前 `1.5/s` 的表达漏了 2π。

将包含被拒点的 20 个估计仅作描述性 K/s 拟合，得到 K≈9.30 rad/(s²·A)，相对复数误差中位约 17%、最大约 47%。这不是通过独立验证的模型，不用于设计 PID。`1/(Js+b)` 是带阻尼的一阶对象，仅在相关频带由 Js 主导时近似积分器；单个非平衡工作点的速度/电流比不是已测得的直流增益。

### 4.3 剩余信号不能直接命名为漂移

扣除同频分量后的残差可能包括噪声、负载扰动、非线性谐波、瞬态和其他频率的真实运动。单靠残差 RMS 或前后两周期差异，不能证明其来源、非平稳性，或证明“加周期不会收敛”。输出 SNR 较低也不等于已经测得传感器分辨率下限；此前将 4 Hz 速度响应约 0.02 rad/s 直接归因为测速分辨率下限，没有独立噪声底或量化测试依据。

原分析器已经在每周期回归中去掉线性趋势。此次比较有/无线性去趋势的结果，部分频点复数估计差可达约 55%，说明处理方式确实重要，但不能由此认定积分漂移主导。四份记录的积分项扫频净变化约 8–16 mA，不支持先前把该项直接认作唯一瓶颈。

### 4.4 周期数与激励幅值的作用

- repeat 定义是逐周期传递比的标准差/汇总幅值，不是均值的标准误；增加周期数不会自动按 1/sqrt(N) 降低此指标。
- 更多周期可以改善均值估计和暴露慢变化；在只有四个周期的数据上，前两周期与后两周期差异不能证明增加周期无效。
- 如果背景扰动近似不变且局部保持线性，提高独立激励可以提高 SNR。现有记录激励幅值均为 0.06 A，没有 0.10/0.11 A 对照，无法断言扰动一定随激励同比例增长。
- 周期增加或幅值提高都不保证模型通过，且需分别评估连续转动空间及局部线性范围。

## 5. 后续建议（未执行）

先不冻结积分、不关闭速度环，不直接用描述性积分器调 PID。

若继续试验，优先只改变一个变量，以可比较的同频、同周期设置核对提高激励幅值后 SNR 和周期一致性是否改善；不要同时改频点、周期数和幅值后再将改善归因于其中某一项。

连续转动预算应按两段 5 s 平滑坡道合计约 5 s 满速等效时间计算，而不是重复计算坡道。以 1 rad/s 目标、工作点等待 2–15 s 为例：

| 计划 | 最长每方向时间/s | 目标积分位移/圈（非实际运动上界） |
|---|---:|---:|
| 原五频点、4 周期 | 74.5 | 8.51–10.58 |
| 0.25/0.5/1 Hz、12 周期 | 126.0 | 16.71–18.78 |
| 0.25/0.5/1 Hz、4 周期 | 70.0 | 7.80–9.87 |
| 仅 0.5 Hz、12 周期 | 56.0 | 5.57–7.64 |

这些是参考目标积分，真实输出端注入会引起额外速度波动，不能作为机械安全限位或实际位移上界。

## 6. 复现文件

- `independent-analysis.json`：四份记录的完整性指标、全部逐周期复数系数、20 个频响、描述性周期重采样结果、描述性拟合、输入 CSV SHA256。
- `analyze.py`：独立分析脚本，仅生成离线结果，不导入或运行固件控制流程。
- 四周期 bootstrap 区间仅展示估计敏感性，不作为经过标定的置信区间；周期间可能不独立。
