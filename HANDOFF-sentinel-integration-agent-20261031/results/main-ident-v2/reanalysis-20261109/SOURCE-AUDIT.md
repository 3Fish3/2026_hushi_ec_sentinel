# 分析器源码独立核查后的确认项

本记录仅保留经主线程源码核对或计算复核的项目；不将独立审阅者推测直接视为事实。

## 已确认

1. `source/robots/sentinel/host/sentinel_identify_analyze.py:54,67-75`：V2以独立输出端电流扰动作工具变量，G=ΣYD*/ΣUD*，互补灵敏度使用控制时基的1−U/D。闭环反馈的存在不是对象辨识失效的充分理由。U是命令电流，不是独立实测转矩，因此估计对象还包含命令到实际执行之间的动态。
2. `sentinel_identify_analyze.py:34,94` 使用2πf，源码Hz换算正确；此前聊天中的1.5/s是解释错误，不是源码该处错误。现有命令尺度3/16384 A/raw，对应正满量程3 A，不能重复乘3。
3. `sentinel_identify_analyze.py:35,63-67`：单周期同时回归常数、线性趋势和正余弦。对均匀采样、局部相位从0开始的单周期，线性时间与sin相关系数约−0.780，标准线性回归条件下的方差膨胀因子约2.55；四周期联合窗口同项约1.04。此为可量化的估计方差问题，不等于回归必然有偏或必须立即换分析器。真实噪声并非已验证白噪声，且相位原点会改变两个谐波分量各自的相关性。
4. `sentinel_identify_analyze.py:69,76`：汇总对象估计用互谱比，repeat却度量逐周期Y/U比的相对散布，两者不是同一个估计量。低频U同频幅值被闭环抑制时，后者会放大周期比的波动；建议研究G本身的跨周期/跨记录不确定性作为补充指标，不能直接以删掉门限来宣布模型有效。
5. `sentinel_identify_analyze.py:37-38,71`：SNR的分母为回归残差RMS，不是独立测得的传感器宽带噪声底，不能直接归因于量化分辨率。
6. `sentinel_identify_analyze.py:79`：moving使用平均方向和绝对速度第10百分位，不保证每个样本连续同向。后续0.10 A记录中，反向0.25 Hz出现近零速段但moving仍为true，是该指标粒度的具体例子；未修改源码或运动保护。

## 不采纳的过强推断

- 不将C、G、T之间的代数关系吻合称为独立证明机械模型正确；它们部分来自相同记录和同一控制结构。
- 不由近似积分趋势直接建议提高Kp、指定新带宽，或断言4 Hz以上没有共振/执行器延迟。
- 不将repeat/SNR的一般相关性当成两者严格等价，也不称现有门限“永远不能通过”；数据里已有通过的点。
- 未独立核验残差峰与转角周期之间的因果联系，不据此确认偏心、齿隙或周期摩擦。
- 仅四周期的bootstrap/jackknife范围不是天然校准的置信区间；跨周期依赖和跨工况差异仍需检查。

结论：对象频响公式本身可解释、单位换算正确；质量指标存在需要评估的局限。原始数据、按原门限计算的usable结果和本次探索性重分析均保留，不改控制器，不应用候选。
