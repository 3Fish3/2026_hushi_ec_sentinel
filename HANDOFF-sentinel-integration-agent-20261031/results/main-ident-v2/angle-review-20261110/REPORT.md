# 转角相关慢点复核（含一处自我更正）

## 结论

**慢点可复现，但正向和反向的慢点位于不同物理转角，因此不是"同一处机械卡点"。**

| 方向 | 慢点转角 | 三次采集一致性 |
|---|---|---|
| 正向 | 约 102–112° | 3/3 一致 |
| 反向 | 约 252–258° | 3/3 一致 |

在 257.5° 处：正向归一化速度 1.040 / 1.026 / 0.993（正常偏快），反向 0.737 / 0.741 / 0.250（明显偏慢）。同一角度只在一个方向慢，说明它是**方向相关**的特征，不是固定位置的机械缺陷。

## 对上一版报告的更正

上一版本在 `REPORT.md` 中写过：

> 正向约 105°、反向约 253°，而 360° − 253° = 107°，即两者指向同一物理关节角。

**这个换算是错的。** 减速时的物理转角本身就是同一个坐标系的读数，不需要再取补角。补齐后反而得到 107°，那是把两个不同位置人为凑到一起。数据不支持"同一物理角度"的说法。

已验证的原始事实：正向最慢点在 102.5–107.5°，反向最慢点在 252.5–257.5°，两者相差约 150°。

## 可复现性（这部分成立）

72 个 5° 分箱、方向归一化后的最小值：

| 记录 | 正向最慢 | 反向最慢 |
|---|---|---|
| 首轮 0.06 A | 107.5°，0.749 | 252.5°，0.732 |
| 第二轮 0.06 A | 102.5°，0.734 | 252.5°，0.736 |
| 0.10 A | 107.5°，0.767 | 257.5°，0.250 |

三轮、两种幅值，正反两个慢点各自稳定复现。这排除了纯随机波动。

## 逐圈深度不单调

以 257.5° 为中心 ±12° 窗口，按累计圈数计算凹陷深度：

| 记录 | 逐圈深度 |
|---|---|
| 首轮反向 | 31.5% 18.4% −20.9% 11.1% 32.9% 20.3% |
| 第二轮反向 | 6.4% 40.3% −5.1% 12.4% 20.4% 37.2% 7.4% |
| 0.10 A 反向 | −32.8% 40.8% **82.6%** 12.6% 25.8% 7.9% 8.6% |

深度随圈数**没有上升趋势**，个别圈甚至为负。因此不支持"多圈累积把线束绞紧"作为主因；0.10 A 那次 82.6% 的极深凹陷是单次事件。

## 已确认停滞事件的归位

0.10 A 反向近停滞发生在关节角 29.625 rad，折算 **257.4°**，落在反向慢点窗口内（该圈深度 82.6%）。所以那次停顿是该慢点在特定条件下加深，不是另一类故障。

## 现有数据不能确定的

1. 具体机械部位：齿轮啮合、轴承/密封阻力、线束局部约束、结构干涉均未被区分。
2. 为什么只在一个方向慢：可能是齿隙方向性、摩擦的方向不对称，也可能是该方向下减速器承载不同，需要拆解或专项试验才能判断。
3. 线性频响模型无法表达这种位置与方向相关的非线性；它持续拉低逐周期重复性，是 0.25 Hz 长期被拒的一个来源。

## 建议（未执行）

- 先做机械与线束专项检查，重点看反向经过 250–260° 时的阻力来源，再看正向 100–115°。
- 在确认前，继续加幅或提高 Kp 都不改变该特征本身，不推荐。
- 若仍需建模，应把这两个角度区间从"线性对象"假设中显式排除，而不是靠调门限让它通过。
