## 本轮观察

1. 计划与 0.06 A 对照相比仅 amplitude_a 不同；正反参数前后及与对照记录均一致。正反分别 61112 / 62092 条，零丢样、零链路超时，6 个原始文件远端与本地 SHA256 全部匹配。
2. 0.25–1 Hz 信噪比多数上升：正向 0.25 Hz 从第二轮 3.53 升至 5.73，正向 1 Hz 从 1.44 升至 2.57；反向 1 Hz 从 1.98 升至 2.85。此前“增加幅值没有作用”的断言不成立。
3. 本轮正向 0.25/0.5 Hz 通过，反向仅 0.5 Hz 通过；1 Hz 正反 repeat=0.251246/0.251654，虽接近但仍高于既有 0.25 门限，未放宽门限凑通过。
4. 2 Hz 正反 SNR=1.78/1.82，4 Hz 为 1.28/0.69，仍不足。幅值提高没有消除所有质量问题。
5. 反向 0.25 Hz 出现近零速片段：本方向相对时间约 25.130–26.600 s，连续约 1.47 s 的 |feedback|<0.10 rad/s，平均反馈约 -0.0149 rad/s，编码器净变化仅 -0.02531 rad；该片段平均命令约 -0.3545 A。它支持该处运动确实接近停滞，而非仅同频估计异常，尚未确定具体机械或控制原因。
6. 反向全扫频约 1.0% 的速度反馈未保持目标方向；这些主要集中于 0.25 Hz。现有 moving 判据仍会通过，因为它基于均值和第 10 百分位，不能把 moving=true 等同于全程没有停滞。
7. 反向全程峰值命令达到 0.4682 A（0.06 A 第二轮为 0.2950 A），说明提高激励的代价应与 SNR 改善一起评估；不再自动提高幅值。
8. 仍为 frequency_response_only，无 PID 候选，也没有应用候选或继续试验。

## 解释边界

逐周期波动、SNR 和模型资格分别核对，不把残差直接命名为机械漂移或传感器量化噪声。
如果本轮改善，只能报告该工况下的观测；既有两轮0.06A本来就有变化，单轮对照不足以确定一般性的因果规律。
command_a 已是 A，扫频均速仅统计 stage 2–6；全部数值和参数对照见 comparison.json。
