# 原地自旋：逐圈规律与转速口径只读复核

分析对象：`run-20261109T113649`，Kp35/Ki3/Kd0持续小陀螺，正式采样20.412秒。未再操作设备、改PID或重新采集。数值由现有wire/samples/CSV与源码核对，源码侧只做只读分析。

## 1. 逐圈规律：相位重复成立，但不能用固定谐波外推

把main机械角按 `mod 2π` 分为24个相位格，每格约39–46个约50Hz样本。去恒定目标后的保持误差均值：

```text
[0.63, 0.61, 0.40, -0.02, -0.37, -0.57, -0.51, -0.31,
 -0.10, 0.07, 0.08, 0.04, 0.01, -0.05, -0.05, -0.11,
 -0.14, -0.22, -0.41, -0.56, -0.59, -0.40, -0.03, 0.38] 度
```

- 相位均值峰峰约 **1.215°**，主要呈一圈一次的正弦形态，并叠加二次成分。
- 将记录按时间前后各半，各自按同一机械相位分格，**两半均值相关系数0.925**，最佳循环位移为0格。
- 全段约11.23圈，支持“扰动随main机械角重复出现”的观察，值得检查转角相关的线束拖曳、负载或几何误差。

但**固定相位谐波不能当作稳定的预测模型**：用前半段拟合、后半段检验时：

| 模型 | 后半段RMSE |
|---|---:|
| 仅线性趋势 | 0.449° |
| 相位一/二次谐波 | 0.489° |
| 相位一/二/三次谐波 | 0.459° |
| 前半段最佳1.076 Hz时间正弦 | 0.549° |

训练集上二次谐波可解释约64%去趋势方差，但后半段并未降低误差。说明相位波形会漂移、幅度或相位会变化；不能直接据此把1.1 Hz定为机械共振，也不能构造固定前馈来抵消。相位重复是**排查线索**，不是已辨识的物理模型。

## 2. 转速口径：两个数字不矛盾，疑点落在底盘19:1配置

本次快页时间基一致（host/毫秒/微秒跨度约20.41秒），主要角速度：

| 量 | 均值 | 含义 |
|---|---:|---|
| `wheel_odom.twist.wz` | **2.87058 rad/s** | 四轮反馈经全向轮逆解得到的底盘转速，使用配置中的19:1与轮半径 |
| `joints.main_yaw.rate_rad_s` | −3.45989 rad/s | main编码器五点因果测速 |
| 由姿态/`rate_V`反解的车体偏航率 | **3.45729 rad/s** | 平台角速度扣除main关节旋转后的车体系Z分量 |

- `−main_rate` 与姿态反解的车体偏航率均值相差约0.0026 rad/s，标准差约0.092；两者是**相近的两种测量／重构**，不是彼此独立真值。
- 轮速反解的底盘转速与姿态反解相差约 **1.2044倍**。
- 源码 `board_app_chassis_config.hpp` 明确写：`chassis_ratio = 19.0f`，注释写明“用户2026-09-26确认，不取CAD引用名268:17”。而 `268/17 = 15.7647`。两者之比：

```text
19 / (268/17) = 1.20522
实测 base / wheel = 1.20439
差异约 0.07%
```

把轮速按该比例换算：2.87058 × 1.20522 = **3.45969 rad/s**，与姿态反解3.45729、main关节速率3.45989吻合到约0.07–0.09%。轮速积分的车体yaw总变化58.610 rad × 1.20522 = 70.638 rad，也与 `joint + heading` 的约−70.579 rad幅度吻合（符号由坐标定义决定）。

因此最可能的解释是：**四轮19:1配置与实际机械传动比不符，实际更接近268/17 ≈ 15.76**。这是配置/标定层面的强线索，尚未由独立测速或拆机核验，不能直接改配置并宣称修复。

补充：轮速里程计四轮一致性残差均值0.125、峰值0.444 rad/s；平移速度模长均值0.022、峰值0.050 m/s，起止轮式xy变化约0.0067 m。本次不是纯定点自旋，但平移很小。轮速残差和轻微平移也说明轮速不是独立惯性真值。

## 3. 对之前疑问的修正

- “轮速2.87与关节−3.46对不上”不再归为打滑优先；**数值几乎完全对应19与268/17两个传动比**。
- 之前按轮速0.457Hz推算的“每圈两次≈1.1Hz”只是数值巧合：更符合数据的是**机械相位约每圈一次/二次重复**；用车体实际约0.55Hz看，二次约1.1Hz。两者不能混成同一个频率证据。
- 固定时间正弦和固定相位谐波在后半段都没有改善预测，不能用来声称已经找到机械共振或可做补偿。

## 4. 结论与建议

1. **保持35/3/0，不自动调PID或烧录。**
2. 下一项优先复核传动比：确认M3508实际减速比、轮径、四轮方向及 `omni_twist` 使用的单位；再用独立转速观测核对。若确认是268/17，单独修正 `chassis_ratio` 后重编，并重新评估轮速里程计与限距保护。
3. 转角相关的轻微晃动仍有约1–2°，可另行检查线束、机械负载与安装；本报告不确认其唯一根因，也不主张加D。
4. 此前限距试走基于轮速里程计，若传动比确实错，其速度/距离换算也会受影响；**在传动比核实前，不继续用该脚本驱动车辆**。轮速里程计始终不能替代物理空间与碰撞防护。
