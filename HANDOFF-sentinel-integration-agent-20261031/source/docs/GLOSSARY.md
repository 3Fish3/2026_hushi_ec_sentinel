# 哨兵底盘与云台联调术语

本词汇表区分主云台相对底盘的运动、相对外界的指向及联调中的观测结论。不记录具体参数、实现方案或验收阈值。

## 运动与参考

**main 主平台**：
由主 yaw 关节带动的云台平台；fire yaw 与 pitch 是其下游关节。
_Avoid_: 将 main 平台与枪口视为同一姿态对象

**主 yaw 机械关节角**：
主平台相对底盘、绕主 yaw 关节轴的转角。底盘和主平台一起转动时，此角度可以不变。
_Avoid_: 世界航向、惯性航向

**主平台惯性航向**：
主平台前向相对局部惯性参考的水平指向。它不是地理正北方位，也不是主 yaw 机械关节角。
_Avoid_: 绝对北向、底盘朝向、编码器角

**机械角保持**：
让主平台维持相对底盘的指定关节角。它与相对外界保持指向是不同目标。
_Avoid_: 惯性稳向

**惯性稳向**：
底盘运动时，主平台仍保持指定的局部惯性指向。主 yaw 机械关节角可以为抵消底盘转动而持续变化。
_Avoid_: 锁死编码器、主轴不能动

**小陀螺模式**：
底盘持续自旋，同时主平台保持指定惯性指向的运行模式。是否有平移是独立的运动条件。
_Avoid_: 将底盘自旋与主平台自转混为一谈

**主平台指向平移**：
以主平台前向和侧向解释操作者的平移意图，而不是以持续自旋的底盘车头为基准。
_Avoid_: 车体系平移

## 调参与观测

**主平台抗扰保持能力**：
在外界扰动下维持指定主平台指向的能力，需结合指向偏差、恢复过程和持续摆动评价。
_Avoid_: 把“更硬”直接等同于更大 Kp、不抖或更高运动速度

**主 yaw 动态跟踪误差**：
主平台在跟随变化目标时，同一参考系下的目标与测量之差。目标不断换向时，误差符号变化本身不是自激振荡的证据。
_Avoid_: 仅凭误差正负交替认定 PID 振荡

**主平台指向摆动**：
主平台相对外界的指向反复变化；这是待解释的现象，不预设来自控制器、机械结构还是估计误差。
_Avoid_: 将主 yaw 编码器变化直接认定为稳向失败

**主平台估计航向偏移**：
航向估计与真实指向之间的偏差。没有独立真实指向或已知真值的对照时，不能仅凭航向与机械关节角不同步判定此偏差。
_Avoid_: 将静止漂移、机械运动和假航向视为同一现象

**main 参数运行覆盖值**：
本次上电期间覆盖固件初始参数的有效值。它与重新上电后采用的固件初始值须分别记录。
_Avoid_: 将在线回读值直接称为已固化参数
