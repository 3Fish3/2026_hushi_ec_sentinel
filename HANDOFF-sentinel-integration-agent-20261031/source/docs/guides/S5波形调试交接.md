# S5 / GM6020 ID4波形调试交接

本包是之前的**S5/v6单GM6020波形调试固件与上位机**, 不是正式APP. 显式配置**CAN1 ID4**, 不修改电调保存的硬件ID. 用于观察实际控制电流命令、PID分项、编码器/RPM和电调反馈raw, 不是自动整定或电机故障判定程序.

## 1. 先确认接线与隔离

- 电机接CAN1, 硬件ID4; 接收`0x208`, 发送电流命令`0x1FE`第4槽. GM6020须支持并启用电流控制模式.
- PC接C板**丝印UART1 / USART6**, **115200 / 8N1**, TX/RX交叉、共地、不接VCC. 不使用APP维护台的UART2/921600, 也不是capture的1Mbps.
- S5只负责这一颗电机, **不承担整车其它电机的停止/失能**; 不与其它CAN发送者并行控制. 切换固件前先停止原APP并断动力, 隔离其它机构动力. 若保留车上机构, 先物理支撑pitch, 检查main活动空间和线束.
- 本角色无需遥控首启/维护授权, **遥控右下不承担S5停止动作**. 保留可靠物理电源硬切; 不把串口停止按钮当作硬件急停.

## 2. 安装与刷固件

解压到短路径, 例如`E:/s5`. 在包根目录执行:

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
.venv/Scripts/python.exe source/boards/sentinel_f407/tools/firmware_tool.py
```

在刷写工具选择 **S5 / GM6020波形调试**, 点“烧录已有固件”. 默认镜像:

```text
source/build/s5-arm-Release/boards/sentinel_f407/sentinel_s1.elf
```

填写本机OpenOCD与scripts目录、ARM GNU工具链、PowerShell7、本包Python路径. 刷已有镜像无需CMake/SDK; 重建才需要. 镜像标识以`s5-gm6020-id4-`开头, 具体身份与SHA256见`PACKAGE.json`.

只擦镜像覆盖扇区并校验, 不做Flash备份、不整片擦除、不改Option Bytes. **`sentinel_s1`文件名不代表只读S1, 本包是可驱动S5**, 不能拿其它角色同名文件替代.

## 3. 打开波形控制台

```powershell
.venv/Scripts/python.exe source/boards/sentinel_f407/tools/motor_bench_console.py --port COM3 --log-dir records/s5
```

Linux也可运行原始脚本; Python须带Tkinter, `--port`改成实际设备路径, `--font`指定本机支持中文的TTF/TTC文件. 不在Linux启动Windows刷写工具流程. 仅想离线看已有波形, 可加`--trace <文件.btrace>`, 不会自动连接或输出.

1. 点击连接, 确认读回 **CAN1 ID4 / RX0x208 / TX0x1FE / slot3(从0计)**, 且反馈在更新. 连接只查询, 不启动电机.
2. 点击“用MCU回读值填入草稿”, 选择电流、速度或位置模式. PID输入直接为物理电流单位, 不手动归一化. 草稿变化不会自动发到MCU.
3. “开始本次测试”才下发参数与目标; 运行中更新目标保留PID历史, 改PID/反馈源则先停止再重新开始. 运行时间0表示持续运行.
4. **S5位置模式需要显式“建立位置参考”**, 将当前角作为本次累计角0; 与APP保留的底盘对齐编码1027不是同一参考. 建立后停止/再启动不重新置0, 不写电调硬件零点.
5. F8或操作面板“停止输出”请求零电流; 采集结束、目标0与停止输出是不同操作. 异常时物理断动力. 不用大步目标或不断加P来定位无响应原因.

两yaw的已通过台架起点可参考速度PID`0.06 / 1.0 / 0`、位置P`7.5`, 电流上限`2.5A`, 速度上限`15rad/s`, 编码器5点测速可选. **这是待调起点, 不是实车负载稳定性保证**, 本包不自动预填或执行它. 原生RPM与编码器测速由本次参数选择.

## 4. 保存能分析的完整波形

- 进入“高频记录 / 回放”, 选择**完整快窗**(不是精简长窗), 数量1024. 名义1kHz, 覆盖约1.024s, 包含实际命令字、反馈raw、PID分项和发送状态.
- 先在停止输出时立即“采集波形”, 可记录零输出基线. 若要看启动/目标更新, 勾选“等待启动/更新触发”, 先采集预置, 然后由你手动开始测试或更新目标.
- 满窗冻结后自动下载, 耗时数秒以上; 心跳继续运行, **下载结束不停止电机**. “结束采样”也不停止电机.
- `.btrace`自动保存并打开; “导出A”生成CSV/PNG与统计. 精简长窗约2.73s但缺少PID分项, 排查本次main不动优先完整快窗.
- 普通JSONL会话日志自动记录; 实时曲线只是约10Hz状态, 不是完整控制波形. 原始文件与候选统一放`records/s5/`, 参数候选需要单独保存.
- 回传**原始.btrace、同次.jsonl、参数候选、实际安装/动力/灯态说明**. 不只发截图或CSV. 命令字和发送accepted不是力矩/上总线证明, `effort_raw`也不要未经依据直接当A.

本包仅离线构建、审计与工具验证, 未烧录/试动. 实机动作仍由用户人工执行. 更多既有功能见`source/docs/guides/GM6020单电机测试.md`; 不附自动试动或扫参流程.
