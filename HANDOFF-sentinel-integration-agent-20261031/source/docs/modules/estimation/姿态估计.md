# 姿态估计与主平台航向

APP当前使用[heading_tilt.hpp](../../../include/ec/estimation/heading_tilt.hpp)/[heading_tilt.cpp](../../../src/estimation/heading_tilt.cpp)的`ec::estimation::HeadingTilt`, 消费链位于`SentinelPerception`. 旧[attitude.hpp](../../../include/ec/estimation/attitude.hpp)/[attitude.cpp](../../../src/estimation/attitude.cpp)保留旋转数学、三轴静态零偏均值与旧EKF示例/离线对照, **APP不再使用旧EKF稳向**.

## 1. 修正的具体问题

旧六状态`[q0,q1,q2,q3,bx,by]`模型在加速度更新后清`dx[3]`, 这既不保持Euler yaw, 也不保持串联主平台前向投影. 固定机体Z残余为0不等于消除了绕世界重力的不可观测方向; 实际注入、K/Joseph更新与归一化亦不一致. 不再用“yaw不会被加速度拉动”的旧描述为该实现背书.

可复现反例: 真姿态固定, 叠加2m/s²、6rad/s旋转水平加速度, 旧APP基线出现约10.37°假航向变化. 比力模长门只能剔除明显异常, 无法区分任意水平加速度与重力. 相关回归使用倾斜安装、非零航向和非零关节, 不以yaw=0特例或关闭加速度融合代替修正.

## 2. 新核心与航向不变量

约定Hamilton四元数`q: S→W`, 安装矩阵为`C→S`. 三轴静态标定和显式已知静止的三轴残余均在C系只扣一次, 然后安装旋转; 当前APP仅使用静态标定, **不从加速度残差学习在线bias**.

1. 陀螺按样本dt右乘指数映射传播`q'=q⊗exp(ω dt/2)`.
2. 新accel先安装旋转, 按允许的时差常速对齐到当前gyro状态时刻. 比力方向在S²上做有界倾斜校正.
3. 调用方提供同一时刻的实际关节锚点:
   `K=R_fire(fire−fire_reference) R_pitch(pitch−pitch_reference)`, `u=Kᵀ forward`.
4. 倾斜候选左乘一个世界Z旋转, 将`R(q_candidate)u`的水平投影调回更新前方向; 再做一次有限浮点残差校正. 这不改变候选的重力方向.

因此**单次有效accel校正不直接注入main heading**, 不冻结真实gyro旋转, 不固定传感器Euler yaw. 原生测试同时要求tilt实际更新、真实三轴及fire/pitch运动被正确跟踪. 无效输入、过大dt、退化投影或反向重力奇点不更新姿态.

不使用协方差或伪造旧P数组. `HeadingTiltConfig`的倾斜时间常数0.5s、校正速率0.5rad/s来自已验证的研究候选, 是待实车验证起点, 不是电机运动限幅. APP沿用已有gyro步长、时效、外推窗口、投影与比力模长配置, 不放宽采样窗口.

## 3. 时序和参考契约

- gyro与accel分开计时; 新accel只消费一次, 不在缺锚点后缓存重放. 无关节参考/历史时gyro继续传播, accel校正跳过, main有效性仍受完整串联重构约束.
- 锚点查询`gyro_us−position_lag_us`, 只用已到达的实际关节历史, 不用now、目标角或未来实测值. 晚于最新样本只可在已有严格窗口内匀速外推并标记.
- 校正前先按粗毫秒时间和微秒年龄淘汰旧历史, 避免跨完整MicroTick回绕复活. 参考变更沿用现有清历史/失效规则.
- 首次/长gap初始化也先检查并对齐accel与gyro, 不先拿超窗旧重力reset. 缺可信对齐量测则等待; 重新prime推进local_epoch并撤销旧alignment, 不设置机械零点.
- `quaternion_from_gravity`取对齐+Z的最短旋转, 一般不等于Euler yaw=0; 小角用atan2避免acos近1舍入放大. `reconstruct`先拒绝非有限/零范数q, 不让`normalized`的identity回退伪造有效反馈.

## 4. 剩余边界与观测

持续加速度仍能形成错误tilt; 有真实三轴运动时, 后续陀螺投影会受到tilt误差影响. 未补偿bias的漂移仍存在, 也不限于世界Z方向. 新核心隔离直接注入, **不是任意运动下的绝对航向保证**, 不补充磁力计、外部航向或自动回零. 固定bias期间应单独记录静止漂移, 不让PID补偿错误反馈.

诊断页3公开每次校正结果、时刻、关节查询/外推、累计结果计数、最后Δheading和开机以来最大绝对Δheading. 低频读取不会漏掉峰值; 各页不是同一采样事件, 应按时刻/代次关联. `accel_updates`现在只计实际应用的倾斜更新, `no_change`另计. 只读采集入口及布局见[正式APP接入说明](../../robots/sentinel/正式APP接入说明.md).

原生回归: `tests/heading_tilt_tests.cpp`、`tests/sentinel_serial_tests.cpp`和既有感知/惯性/协议契约. `tests/heading_geometry.hpp`仅是回传board2的回归夹具, 不自动回填生产配置. 数值测试容差、ARM静态栈审计和实物精度验收各自分开.
