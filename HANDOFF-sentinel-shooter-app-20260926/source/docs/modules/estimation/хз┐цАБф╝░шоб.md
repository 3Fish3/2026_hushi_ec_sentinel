# 姿态估计 (AttitudeEstimator)

源码: [attitude.hpp](../../../include/ec/estimation/attitude.hpp)、[attitude.cpp](../../../src/estimation/attitude.cpp), 类型位于 `ec::estimation`.
契约测试: `tests/input_imu_kinematics_tests.cpp`; 采样来源见 [BMI088 惯导](../drivers/BMI088惯导.md).

## 1. 解决什么问题

陀螺积分会漂, 加速度计长期可靠但动态下噪声大. 这里用固定尺寸六状态四元数 EKF 把两者融合: 状态是 `[q0,q1,q2,q3,bx,by]`, 量测只用加速度 (重力方向).

它**不负责**: 磁力计/外部 IMU 融合、零速检测、安装角标定自动化、把姿态直接接到某个环路上. 姿态参与哪些环路是应用层决策, 见 [Checklist F09/P06](../../robots/sentinel/现有能力与待确认Checklist.md).

## 2. 已知边界

- **Z 轴零偏不估计**: 绕重力轴的 yaw 分量不可观测, 因此 `gyro_bias_rad_s[2]` 恒为 0, 量测也不修正 yaw. 需要绝对航向必须另加参考 (磁力计、外部 IMU、机构编码器), 不能靠长时间积分"等它收敛".
- `chi_square_threshold` 用于丢弃与重力方向严重不符的加速度样本 (例如撞击、强振动), 丢弃只计数 (`measurement_skips`), 不改变姿态估计的连续性.
- `predict()` 可以在没有加速度样本时单独调用: 短时间内退化为陀螺积分, 并计入 `predictions_only`.

## 3. 配置

| 字段 | 默认值 | 来源与限制 |
|---|---|---|
| `process_noise_quaternion` | 10.0 | 旧仓库 `ins_task` 的有效配置 |
| `process_noise_bias` | 0.001 | 同上 |
| `measure_noise` | 1e6 | 同上 |
| `fading` | 1.0 | 渐消因子, 1 表示不额外放大协方差 |
| `accel_lpf_s` | 0.0 | 加速度低通时间常数; 旧代码另有 0.0085 的常量但没有接入该滤波器, 这里保持等价行为 |
| `chi_square_threshold` | 1e-8 | 样本剔除门限 |

默认值是**参数参考与量纲换算的结果, 不是行为等价迁移**, 也没有经过本车实机验证. 机械负载、安装刚度与振动环境都不同, 需要重新评估时按实际数据调整, 而不是"沿用旧值就一定稳定".

## 4. 使用与安装方向

```text
AttitudeEstimator estimator{config, install_rotation};  // install_rotation 默认单位阵
reset(q0, gyro_bias);                                   // 复位姿态与协方差
update(gyro_sensor_rad_s, accel_mps2, dt_s);            // 融合一步
state();                                                // 四元数/欧拉角/协方差相关统计
```

`install_rotation` 表达"传感器坐标系 → 机体坐标系"的固定安装关系; 转换在估计器内部完成, 因此上层拿到的是机体系结果. 角度约定为 ZYX (`roll_pitch_yaw_rad()`), 与旧代码的 Pitch/Roll 命名顺序不同, 迁移旧参数时不能只看名字.

## 5. 常见错误

- 把 `state().roll_pitch_yaw_rad[2]` 当成绝对航向: 它是积分得到的相对量, 会缓慢漂移.
- 传未换算单位的角速度 (deg/s) 或加速度 (g): 必须是 rad/s 与 m/s².
- `dt_s` 用固定常数代替实际间隔: 采样间隔变化时会把噪声当运动, 应使用样本自己的时间戳差.
- 单任务拥有: 不要在多个任务里同时 `update()` 同一个估计器; 跨任务读取用快照, 不要读半更新的内部状态.

## 传播约定与零偏分层 (修复后口径)

- **四元数传播**: 机体系角速度对应 `q' = normalize(q + 0.5 * (q ⊗ ω) * dt)` —— 右乘。
  F 矩阵的四元数块与偏置两列都按同一约定给出；左乘会在非零初始姿态下给出反号的机体系分量。
- **零偏分两处, 不能混为一谈**:
  - 静态标定零偏 (`set_gyro_calibration_rad_s`): **传感器系三轴**, 在安装旋转**之前**只扣一次；
  - 在线残余零偏: EKF 状态, 在**机体系 X/Y** 上估计, 与标定值叠加生效。
  扣偏顺序固定为: 原始测量 − 标定(传感器系) → 安装旋转 → − 在线残余(机体系)。
- **协方差**: 量测更新用 Joseph 形式 `P = (I−KH)P(I−KH)ᵀ + K R Kᵀ`。本滤波器的 K 经过自适应
  缩放与零偏行缩放改写, 不再是"最优增益", 因此 `(I−KH)P` 既不保证对称也不保证半正定。
  传播与量测更新后各做一次对称化, 只为消除 float 累加舍入 (P 量级 1e5 时实测可达 1e-4 相对量级)。
- **可观测性**: 加速度量测看不到绕重力轴的转动, 因此 yaw 不会被量测拉向零; Z 轴残余零偏不估计,
  但**静态标定的 Z 分量会扣除** (外部标定窗口给出的三轴零偏可直接使用)。
