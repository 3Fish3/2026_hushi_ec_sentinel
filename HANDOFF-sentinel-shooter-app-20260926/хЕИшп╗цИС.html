拨弹与双摩擦轮独立调试 HANDOFF

本包在同一轮测试中调试左右摩擦轮和唯一拨弹电机, 不要求更换两份固件. 首轮空机构/无弹测试, 不自动发弹、不自动扫参数. 底盘和云台撤输出, 不作为本次控制依赖.

1. 接线与已确定参数

机构接线/人工设置ID目标单位
左摩擦轮M3508CAN2 ID5, 反馈0x205电机转子rad/s, 本版1:1
右摩擦轮M3508CAN2 ID6, 反馈0x206电机转子rad/s, 本版1:1
唯一拨弹M2006CAN2 ID7, 反馈0x207减速后输出轴rad/s, 用户确认36:1

三颗共用0x1FF帧但每槽按各自电调换算电流. GM6020在CAN1, 不要照裸台架把电机挪到同一总线, 也不要把此处拨弹ID7改成台架ID3. 同CAN2的底盘ID1–4只收到零电流.

拨弹以用户截图红框那一颗为准. 不因为CAD有其它M2006模型引用增加第二执行域, 不把CAD零件名作为叠加传动倍率的依据.

2. 准备、刷写与连接

1. 清空弹丸, 检查轮子、拨盘紧固及防护, 不把手或物品放入旋转区域. 物理硬切可用; pitch本版失能, 有下落风险的机构先物理支撑.

2. DT7接DBUS, 遥控右下, 断动力后通过SWD烧录前缀app-shooter-的本包固件.

3. PC串口接C板丝印UART2 / USART1 / 921600, TX/RX交叉、共地、不并接VCC, 不与Jetson并联TX.

4. 建议解压到短路径E:/shooter, 包根目录执行:

3. 上电与同轮测试

1. 右下停止时供电、连接. 核对镜像标识和三颗反馈. 右摩擦轮过去有异常记录, 在线只证明通信, 不等于机械已正常; 不在线或卡滞先检查, 不靠加PID硬顶.

2. 切右上＋左中, 点击“申请维护”. 保留遥控首启; 右下撤输出. 其它档位待机, 摇杆与拨轮不产生动作目标. 单纯连接不会运动.

3. 先勾选三颗目标通道并填0. 每次只改一颗, 另外两颗保留0. 每次点击“下发 / 更新目标”; 这会提交完整目标包.

4. 摩擦轮逐颗: 从小速度开始, 例如+5 → 0 → -5 → 0 rad/s, 检查实际轮位、转向、跟随与振动. 确定左右轮共同夹送所需的方向后, 才同时下发双轮目标. 不默认“左右同号”就一定夹送.

5. 拨弹: 从输出轴+0.2 → 0 → -0.2 → 0 rad/s开始. 正目标时勾选“此包允许正向拨弹(草稿)”再提交, 否则会ACK接受但执行显示无许可. 负目标反转和零目标不需要正向许可. 用这轮动作核对实际供弹方向.

6. 若拨弹+号实际是退弹, F8/右下并记录, 在配置中修正direction后重建. 不把负目标长期当作供弹来绕过正向许可. 初始三个电机方向均为原生+1, 是待人工核对值.

7. 单颗正常后, 同时下发双摩擦轮与拨弹目标, 仍保持无弹. 可在同一会话逐项调PID并读回. 不要求先完成云台标定或稳定保持; 当前没有额外“摩擦到速后才允许拨弹”的门槛.

8. 任一摩擦轮反馈故障会撤双轮及拨弹; 拨弹自身故障只撤拨弹. 未调云台故障不阻塞此独立测试. 目标/会话超时、人工停止及电调协议边界保持有效.

测试后F8撤目标、右下停止, 确认旋转停下再接近机构. 速度0是零速闭环, 不等于撤电流. F8不自动断电. 后续有弹和测速仪测试单独安排, 本包交付不表示实弹测试已授权或完成.

GUI中的DJI速度PID已是电流单位, 不再手工除电流上限. 先改电流上限再设物理PID; 编辑仅为草稿, 单项应用后看MCU读回. 候选文件仍保存协议原生数值, 不手工混用两种单位.

热改仅在RAM, 断电恢复编译值. 保存参数候选和日志, 在发射参数表.csv记录原生方向、实际采用参数和异常. 固化入口:source/boards/sentinel_f407/include/board_app_mechanism_config.hpp; 方向、传动和构造期量程需重建重刷. 这些测试配置不自动成为正式比赛的运动限幅.
