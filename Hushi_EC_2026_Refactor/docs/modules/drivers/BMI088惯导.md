# BMI088 惯导响应解析 (BMI088 IMU)

源码: [bmi088.hpp](../../../include/ec/drivers/bmi088.hpp)，位于 `ec::drivers` 命名空间。对应契约测试: `tests/core_tests.cpp` 中的 `bmi088_contracts`。

## 1. 为什么需要专门的 BMI088 解析组件？

RoboMaster C 型开发板板载了 Bosch BMI088 高性能 6 轴惯性测量单元（包含 3 轴加速度计与 3 轴陀螺仪）。
许多刚接触该芯片的队员常会陷入两个严重的陷阱：
1. **SPI 通信协议的“Dummy 哑字节”陷阱**：
   BMI088 的加速度计和陀螺仪在硅片内部是两个独立的硬件内核，它们的 SPI 通信协议格式**完全不同**！
   - **加速度计读取**：发送完 1 字节寄存器地址后，硬件要求紧接着接收一个**无意义的“Dummy 哑字节”**，随后才是 6 字节的数据（总收发长度为 **8 字节**）；
   - **陀螺仪读取**：发送完 1 字节寄存器地址后，**立即直接输出** 6 字节数据，中间没有哑字节（总收发长度为 **7 字节**）。
   如果软件图省事统一“丢弃第 1 个字节”，加速度计的数据就会发生 1 字节的错位，导致解析出来的重力加速度面目全非！
2. **机构末端合成运动的解耦陷阱（架构设计红线）**：
   在哨兵或双 Yaw 轴云台上，如果板载 IMU 随主控板一同安装在枪管/Pitch 轴机构末端，**IMU 测得的角速度是底盘、两级 Yaw 轴与 Pitch 轴的复合物理运动！**
   **严禁在未经过运动学解耦的情况下，直接拿该 IMU 的角速度作为单一 Yaw 电机的闭环反馈！** 系统须具备 IMU 失效时降级至编码器闭环的能力，但切换条件和具体动作仍需机构设计确认；本解析模块不实现或保证无扰切换。

## 2. 模块职责与边界

- **纯协议与量程换算**：本模块负责剔除 SPI 传输占位字节、提供标准初始化寄存器序列、并将原始数字读数转换为标准国际单位制（$m/s^2$ 与 $rad/s$）。
- **不负责硬件总线事务**：本模块不直接调用 HAL SPI 读写，不负责片选引脚（CS）的拉高拉低，不包含卡尔曼姿态解算算法，也不控制板载恒温加热电阻。

## 3. 主机可运行示例

下面的示例演示了加速度计 8 字节 SPI 响应的剥离，以及转换为标准重力加速度的过程：

```cpp
#include "ec/drivers/bmi088.hpp"
#include <cmath>
#include <iostream>

// 主机可运行示例: 演示 BMI088 加速度计 SPI 响应报文的剥离与单位换算
int main() {
    // 1. 构造一个模拟的 8 字节 SPI 接收缓冲区
    //    布局说明:
    //    - rx[0]: 发送寄存器地址阶段对应的 MISO 占位字节 (无有效数据)
    //    - rx[1]: 加速度计 SPI 读操作强制要求的 Dummy 哑字节 (丢弃)
    //    - rx[2..7]: 6 个字节的原始加速度数据 (X轴低/高, Y轴低/高, Z轴低/高)
    //    这里在 rx[6..7] 构造了 Z 轴重力加速度 (约等于 1G, 9.8 m/s^2) 的原始数字量
    const std::uint8_t rx_buffer[8]{0, 0, 0, 0, 0, 0, 0x55, 0x15};

    // 2. 提取出干净的 6 字节原始数据
    std::uint8_t raw_data[6]{};
    if (!ec::drivers::parse_bmi088_accel_spi_read(rx_buffer, raw_data)) {
        return 1; // 缓冲区长度校验失败
    }

    // 3. 按照当前硬件配置的 ±6g 量程，将原始数字量转换为国际标准单位 m/s^2
    const auto accel = ec::drivers::parse_bmi088_accel_6g(raw_data);
    if (!accel) {
        return 2; // 转换失败
    }

    // 4. 校验 Z 轴测量结果 (accel 是包含 3 个 float 的 std::array: {ax, ay, az})
    //    在静止放置状态下，Z 轴加速度应当非常接近标准重力加速度 9.8 m/s^2
    const float az = (*accel)[2];
    if (std::fabs(az - 9.8f) < 0.02f) {
        return 0; // 契约验证通过！
    }

    return 3;
}
```

## 4. 物理单位与量程映射契约

| 解析函数 | 要求的硬件寄存器配置 | 转换后的物理单位 |
|---|---|---|
| **`parse_bmi088_accel_6g`** | 加速度计量程设置为 **$\pm 6g$** | 米每二次方秒 (**$m/s^2$**) |
| **`parse_bmi088_gyro_2000`** | 陀螺仪量程设置为 **$\pm 2000^\circ/s$** | 弧度每秒 (**$rad/s$**) |
| **`parse_bmi088_temp_c`** | 芯片内部温度传感器 | 摄氏度 (**$^\circ C$**) |

> **关键硬件纪律**：
> 软件解析函数的比例常数与硬件寄存器的量程设置是严格绑定的。如果在 CubeMX 或初始化代码中修改了量程（例如把陀螺仪改成了 $\pm 1000^\circ/s$），必须同步更新解析函数，严禁只改一方导致控制量失真！

## 5. SPI 通信时钟与板级配置

根据 Bosch 官方数据手册：
- 加速度计与陀螺仪在 SPI 模式下支持的最大时钟频率上限为 10 MHz。
- 在我们的 Sentinel F407 板级配置中，SPI1 挂载在 APB2 总线（84 MHz），采用 16 分频配置，实际运行在 **5.25 MHz**（Mode 3），低于上述通信频率上限，但这不保证接线、时序或实际通信必然可靠。详细配置见 [Sentinel F407 板级说明](../../boards/sentinel_f407/README.md)。

## 6. 设备层: Bmi088Device

源码: [bmi088_device.hpp](../../../include/ec/drivers/bmi088_device.hpp)、[bmi088_device.cpp](../../../src/drivers/bmi088_device.cpp), 类型位于 `ec::drivers`.

上面的解析函数只处理"字节 → 物理量". 设备层补上初始化序列、芯片 ID 核对与采样时效:

- `Bmi088Bus` 是平台接口 (`read`/`write`/`delay_ms`), 由板级或测试实现; 设备层不认识 HAL.
- `init()` 按 `bmi088_init_steps()` 写配置寄存器, 再核对加速度计与陀螺仪芯片 ID; 不匹配时返回 `chip_id_mismatch` 且不标记为已初始化.
- `read(now)` 一次读取加速度/角速度/温度; 任一次传输失败都不更新样本 (`transport_error`), 时间戳倒退返回 `time_regression`.
- `reading(now)` 只在样本仍在 `sample_ttl` 内时返回; `dt_ms` 是本次与上次成功读取的间隔, 可直接用于姿态估计的 `dt_s`.

姿态融合见 [姿态估计](../estimation/姿态估计.md). 板级 SPI 时钟与片选纪律见 [Sentinel F407 板级说明](../../boards/sentinel_f407/README.md).
